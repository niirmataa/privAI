# przemyslenia

Ten folder zawiera materialy pomocnicze:

- audyty,
- szkice architektoniczne,
- propozycje migracyjne,
- logi,
- kontekst roboczy,
- dokumenty eksploracyjne.

To nie jest glowny rdzen drogi systemu.

Za glowny rdzen w `spec/PRIVAI_V0_PRIVATE_COMPUTE/` uznajemy tylko:

- `PRIVAI_V0_DIRECTION_RESET_PRIVATE_COMPUTE_NETWORK.md`
- `PRIVAI_V0_DIAGRAMS.md`
- `PRIVAI_V0_COMPUTE_LEASE_SETTLEMENT_DIRECTION.md`
- `PRIVAI_V0_DOCS_TREE.md`

Folder `tasks/` pozostaje osobna przestrzenia robocza dla promptow i outputow modeli.
